# LangChain Retrievers

This folder contains examples of different **LangChain retrievers** used in Retrieval-Augmented Generation (RAG) applications. Each example demonstrates how a retriever works, when to use it, and how it can improve information retrieval from a knowledge base.

## Topics Covered

* Similarity Retriever
* MMR (Maximum Marginal Relevance) Retriever
* MultiQuery Retriever
* Contextual Compression Retriever

## Technologies Used

* Python 3.12+
* LangChain
* LangChain Community
* LangChain Classic
* Google Gemini
* FAISS
* ChromaDB
* Hugging Face Embeddings
* Google Gemini Embeddings


## Available Retrievers

### Similarity Retriever

Returns the most semantically similar documents using vector embeddings.

### MMR Retriever

Balances relevance and diversity to reduce duplicate search results.

### MultiQuery Retriever

Uses an LLM to generate multiple variations of the user's query, improving document recall.

### Contextual Compression Retriever

Retrieves relevant documents and compresses them using an LLM, keeping only the most useful information.


## Learning Outcomes

By completing these examples, you will learn how to:

* Build Retrieval-Augmented Generation (RAG) pipelines
* Work with different LangChain retrievers
* Use FAISS and ChromaDB as vector stores
* Generate embeddings using Google Gemini and Hugging Face
* Improve retrieval quality with advanced retrieval techniques
* Understand the strengths and trade-offs of different retrievers
