# LangChain Text Splitters

This repository contains examples of different **LangChain Text Splitters** used to divide large documents into smaller, meaningful chunks. Text splitting is a fundamental step in **Retrieval-Augmented Generation (RAG)**, enabling Large Language Models (LLMs) to efficiently process and retrieve relevant information.

## 📚 Topics Covered

- Character Text Splitter
- Recursive Character Text Splitter
- Language-Based Text Splitter
- Token-Based Text Splitter
- Semantic Chunking
- Chunk Size and Chunk Overlap
- Practical Examples

## 🛠️ Tech Stack

- Python 3.12+
- LangChain
- LangChain Text Splitters
- tiktoken
- Jupyter Notebook


## 🎯 Learning Outcomes

After completing this repository, you will understand:

- How LangChain text splitters work
- When to use each splitter
- Best practices for chunking documents
- How text splitting improves retrieval performance
- How chunking is used in RAG applications
