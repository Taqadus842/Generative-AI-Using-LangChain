# LangChain Vector Stores

A collection of examples demonstrating how to use different vector databases with LangChain for Retrieval-Augmented Generation (RAG) applications.

## Technologies

- LangChain
- Google Gemini Embeddings
- ChromaDB
- FAISS
- Python

---

## Implemented Vector Stores

### ChromaDB

Features

- Create vector database
- Store documents
- Persistent storage
- Load existing database
- Similarity search
- Retriever



---

### FAISS

Features

- Create vector index
- Store embeddings
- Save index
- Load index
- Similarity search
- Retriever
