# 📚 Topics Covered

## 1. LangChain Models

The `Langchain Models` folder contains implementations of different model types supported by LangChain.

---

## 🔹 LLMs (Large Language Models)

Location: Langchain Models/LLMs/

Learning objectives:

- Understanding LangChain LLM wrappers
- Connecting external and local models
- Sending prompts to language models
- Receiving generated responses

Examples include:

- Hugging Face models
- Ollama local models
- OpenAI-compatible models

---

## 🔹 Chat Models

Location: Langchain Models/ChatModels/

Learning objectives:

- Working with conversational AI models
- Understanding messages:
  - System messages
  - Human messages
  - AI messages

Implemented concepts:

- Chat model initialization
- Prompt passing
- Response generation
- Multi-turn conversations

---

## 🔹 Embedding Models

Location:Langchain Models/EmbeddingModels/

Learning objectives:

- Understanding text embeddings
- Converting text into numerical vectors
- Measuring semantic similarity

Implemented concepts:

- Generating embeddings
- Comparing vector similarity
- Preparing data for vector databases
